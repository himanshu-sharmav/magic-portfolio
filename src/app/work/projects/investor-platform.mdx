## The product problem

Investor onboarding combines entity details, eligibility, documents, and fund-specific workflows. People need to see what is complete, what is missing, and what can happen next.

## What I delivered

I built a **four-step investor passport** for entity details, accreditation, tax, and AML/KYC. The implementation connects Django APIs and React forms with completion tracking and sequential validation.

I implemented subscriptions for invited fund classes and a **three-level portfolio drill-down** over existing APIs, helping users navigate from aggregate views to the underlying portfolio information.

## Communication and account visibility

I built LP/GP messaging with S3 attachments and scoped deletion/audit behavior. I also implemented a funding workspace with account summaries and ACH lifecycle activity.

I owned these workflow features and their backend/frontend contracts as part of the wider product team.

**Stack:** Django REST Framework, React, PostgreSQL, AWS S3.
