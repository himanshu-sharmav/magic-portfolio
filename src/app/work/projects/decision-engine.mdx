## What it does

A configurable decision service evaluates JSON rules and returns approve, reject, or review outcomes with the reasons and triggered rules behind each decision.

## What I built

- Restricted expression evaluation for rule conditions.
- Weighted scoring with hard-rejection overrides.
- Payload-hash duplicate detection and persisted decision results.
- Unit and API regression tests for evaluation behavior.

This independent backend project makes each decision traceable to its inputs, rules, and scoring contributions.

**Stack:** FastAPI, Python, SQLAlchemy.
