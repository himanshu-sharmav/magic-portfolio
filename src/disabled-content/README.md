# Disabled template content

The original blog and gallery route sources are preserved here, outside Next.js App Router discovery. These are template examples and are not Himanshu’s published articles or gallery.

Their route flags remain disabled in `src/resources/once-ui.config.ts`. If enabling a future blog, move its route sources back under `src/app/`, replace all sample content with authored work, and update metadata and public media before enabling the route flag. Sitemap reads are conditional on the route flags; active portfolio pages read only the work/project collection.
